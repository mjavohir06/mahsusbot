# Mahsus bot

Telegram anime bot ([animebot](https://github.com/mjavohir06/animebot) ning kengaytirilgan versiyasi).

**Texnologiyalar:** Node.js, grammY, Express

## Imkoniyatlar
- Anime'ni **kod**, **nom** yoki **rasm** bo'yicha qidirish
- Barcha animelar ro'yxati va shorts videolar
- Majburiy kanal obunasi
- Admin panel va sozlamalar: anime/shorts qo'shish, ommaviy xabar, statistika, kanallarni boshqarish
- Xatolik bo'lsa bot egasiga avtomatik xabar

## Ishga tushirish

```bash
npm install
cp .env.example .env   # BOT_TOKEN= ga @BotFather bergan tokenni yozing
npm start
```
